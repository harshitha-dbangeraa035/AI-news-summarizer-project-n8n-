# 🤖 AI News Summarizer

An automated AI news summarization project built using **n8n, RSS Feeds, Google Gemini, and Gmail**.

## 🚀 About the Project

This project automatically collects the latest **AI and technology news**, summarizes the articles using **Google Gemini**, and sends the summarized news directly to your email.

## 🔄 Workflow

**Schedule Trigger → RSS Feed → Aggregate → Google Gemini → Gmail**


## 🛠️ Technologies Used

- n8n
- RSS Feeds
- Google Gemini
- Google AI Studio
- Google Cloud
- Gmail API
- OAuth 2.0

## ✨ Features

- Automatically fetches the latest news
- Summarizes news using Gemini AI
- Organizes AI and technology news
- Sends a newsletter through Gmail
- Runs automatically on a scheduled time

## ⚙️ Requirements

- n8n Account
- Google Account
- Google Gemini Access
- Gmail API
- RSS Feed URLs
